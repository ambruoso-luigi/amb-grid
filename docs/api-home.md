# AMB Grid API reference

This reference documents the public JavaScript API of AMB Grid. Create a grid
with `AMB.table(options)`, then use the returned controller for the managed
grid lifecycle, CRUD operations, data, navigation, validation, and cleanup.

The namespace also exposes editor, validator, formatter, and parser factories,
along with public lookup, date, and UI helpers.

For concepts, setup, and examples, read the [README](../README.md). For module
ownership and lifecycle boundaries, read the [architecture guide](../ARCHITECTURE.md).
